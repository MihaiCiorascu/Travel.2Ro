# Travel.2Ro - Romania Travel Guide

**Travel.2Ro** is my first website, developed in high school. It serves as a comprehensive guide for exploring Romania, helping travelers easily plan their trips.

## Key Features

- **Accommodation Listings**:
  - Detailed information about lodging options, including contact details.
  
- **Tourist Attractions**:
  - A curated guide to Romania's top destinations and must-see landmarks.

- **User-Friendly Design**:
  - An intuitive interface for smooth navigation and a seamless user experience.

---

This project reflects my early interest in web development and my passion for showcasing Romania's beauty. I hope it inspires many to explore this wonderful country!
